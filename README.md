# Disable-WinSpace
Powershell to disable Win&amp;Space keyboard language switch shortcut without needing any powertoy or autohotkey and running in userspace , no admin rights needed.

You can start it with a %SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe -NoProfile -WindowStyle Minimized -File "PATH...\Disable-WinSpace.ps1" link (also from the Shell:Startup folder)
